AWS Docker Nginx Portfolio

DockerとNginxを利用したWebサーバー構築学習プロジェクト

1. プロジェクト概要

DockerとNginxを使用してWebサーバー環境を構築し、 静的なWebページを配信することを目的とした学習プロジェクトです。 AWS EC2へのデプロイも想定し、インフラ構築の基礎を学習しています。

2. 使用技術

  • Docker：アプリケーション実行環境の構築
  • Docker Compose：コンテナの起動・管理
  • Nginx：WebサーバーによるHTTPリクエストの処理
  • HTML / CSS：Webページの作成
  • AWS EC2 / Linux：クラウドサーバー構築の学習

3. 学習・検証項目

  • Dockerfileを使用したイメージのビルド
  • Docker Composeによるコンテナ管理
  • ホストとコンテナ間のポートマッピング
  • Nginxによる静的コンテンツの配信
  • コンテナの状態確認とログ調査

4. 今後の改善予定

  • AWS EC2環境へのデプロイと動作検証
  • アクセス制御とセキュリティ設定の見直し
  • 障害発生時の調査手順と解決記録の整備
